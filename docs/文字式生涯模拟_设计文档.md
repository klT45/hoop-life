# 文字式篮球生涯模拟 · 设计文档

> 对标：虎扑《我创造的完美球员》（现役/传奇模式）
> 定位：**文字决策 + 属性加点 + 分享卡**，不做沙盒经营。
> 数据底座：`BBallGMDraftClasses-main/`（77 赛季 / 4,786 名球员）

---

## 一、核心玩法循环（一把 10–15 分钟）

```
选年代 → 选位置 → 抽球队 → 13 轮「夺取属性」 → 揭幕 OVR + 模板
   ↓
82 场常规赛模拟 → 赛季评奖 → 季后赛 → 休赛期（加点 + 剧情事件）
   ↓
年龄增长 → 属性自然衰减 → 下一赛季 …… → 退役 → 生涯评级 + 分享卡
```

**最有意思的设计是「夺取属性」**：不是自己捏数值，而是从真实球员身上"抢"能力。
这一条恰好让我们的数据集从"背景素材"变成**游戏核心内容**。

## 二、13 项属性（对齐虎扑游戏）

| 键 | 中文 | 说明 |
|---|---|---|
| threePT | 三分 | 远投 |
| MID | 中投 | 中距离 |
| FIN | 终结 | 篮下终结 |
| DNK | 扣篮 | 观赏性/爆发 |
| HAN | 护球 | 控球 |
| PAS | 传球 | 组织 |
| PDEF | 外防 | 外线防守 |
| IDEF | 内防 | 内线防守 |
| BLK | 盖帽 | 护框 |
| REB | 篮板 | 篮板 |
| ATH | 运动 | 速度/弹跳 |
| STR | 力量 | 对抗 |
| CLU | 关键 | 关键球 |

值域 **25–99**。OVR 等级：≥95 超级巨星 / ≥85 全明星 / ≥75 首发 / ≥65 轮换 / 其余 边缘。

## 三、属性映射：我们的 16 项 → 游戏 13 项

| 游戏属性 | 由 Basketball GM 16 项推导 |
|---|---|
| threePT | `tp` |
| MID | `fg` |
| FIN | `ins` × 0.6 + `dnk` × 0.4 |
| DNK | `dnk` |
| HAN | `drb` |
| PAS | `pss` |
| PDEF | `diq` × 0.6 + `spd` × 0.4 |
| IDEF | `diq` × 0.6 + `stre` × 0.4 |
| BLK | `hgt` × 0.5 + `jmp` × 0.3 + `stre` × 0.2 |
| REB | `reb` |
| ATH | `spd` × 0.5 + `jmp` × 0.5 |
| STR | `stre` |
| CLU | `oiq` × 0.5 + `endu` × 0.2 + 稳定度 0.3 |

**⚠️ 必须先做年代归一化**（本项目最大的坑）：
原数据里 1950 年顶级球员 OVR ≈ 40–56，1990s 峰值 88。
若直接映射，1950 年代的球员会弱到没法玩。
→ **按赛季把所有属性归一到 [25,99] 分位**，让每个年代自成一个完整的强度体系。
这是"能从不同年代开始玩"能成立的前提。

## 四、OVR 权重（各位置，来自实测）

`OVR = Σ(属性值 × 该位置权重)`，缺省权重 0.07。

| 位置 | T1（最高） | T2 | 低收益 |
|---|---|---|---|
| PG | 护球 0.14、传球 0.14 | 三分、中投、外防 | 篮板、盖帽、力量 |
| SG | 三分 0.12、中投 0.12 | 终结、关键、外防 | 盖帽、篮板 |
| SF | 三分/中投/终结/外防 各 0.10 | 扣篮、护球、内防、运动 | 盖帽 |
| PF | 终结 0.12、内防 0.12 | 篮板、外防 | 三分、传球、关键 |
| C | 终结 0.14、内防 0.14 | 篮板、盖帽、力量 | 三分、中投、护球、传球、关键 |

**⚠️ 陷阱：`关键` 只拉高 OVR 展示，几乎不提升球队夺冠胜率**（虚高属性）。
要在 UI 上让玩家能感知到这一点，否则玩家会误以为堆关键最优。

## 五、球队实力与胜负

```
球队实力 = 40% 进攻 + 40% 防守 + 20% 阵容深度
  进攻分项 ← 三分、中投、终结、传球、护球、扣篮、运动
  防守分项 ← 外防、内防、盖帽、篮板、运动、力量
  阵容深度 ← 队内前 7 轮换球员总评加权

netRating = (offA-offB)×0.4 + (defA-defB)×0.4 + (depthA-depthB)×0.2 + 种子加成
winProb   = clamp(0.5 + netRating/25, 0.15, 0.85)
```

属性递减曲线（拉开普通与顶级差距）：
```js
attrFactor(v) = ((clamp(v,25,99) - 25) / 74) ** 0.85
af(v) = attrFactor(v) ** 1.5
```

## 六、单场数据生成

- 出场时间：`30 + rand×8`（季后赛 38），再乘年龄使用率偏置
- 使用率：位置核心进攻属性均值 → `af()`；`OVR>75` 时 `usageScale = 1+(OVR-75)×0.018`
- 命中率：`base + (attr-50)×attrFactor`，总分 >220 → +1.5%，<180 → -1.5%；再乘 `0.92+rand×0.16`
- 篮板：`af(REB) × (总分/200) × 12 × 时间系数 × (0.7+rand×0.6)`
- 助攻：`af((PAS+HAN+CLU)/3) × (总分/200) × 9 × …`
- 失误：`max(0.5, fga×0.2×(1 - af((HAN+CLU)/2)×0.4))`

## 七、伤病与衰减

- 年龄基础伤病率随年龄上升；大伤额外概率
- 带伤作战：属性 ×0.72（大伤）/ ×0.82（中）/ ×0.90（轻），下限 35；胜率乘数 0.86/0.92/0.96
- **年度属性漂移**：
  - 快速衰退：`ATH / DNK / PDEF / BLK / IDEF / REB`
  - 中速衰退：`FIN / STR`
  - 慢速技术项：`threePT / MID / HAN / PAS / CLU`

## 八、生涯结构

- 起始 18–19 岁新秀 → 退役（约 36–40 岁）
- 每赛季：常规赛 → 评奖（MVP/最佳阵容/DPOY/最佳新秀/第六人）→ 季后赛 → 休赛期
- 休赛期：**属性加点**（补短板）+ 剧情事件（伤病抉择/交易/合同/场外）
- 退役：按总数据 + 荣誉算评级 **D / C / B / A / S / SS / SSS**
- 产出**竖版分享卡**（能力圈 + 评级圈 + 生涯数据 + 效力球队 + 奖杯墙）

## 九、明确不做（保持"不太复杂"）

❌ 商店 / 装备词缀 / 开箱碎片
❌ 体力条 / 看广告回体力
❌ 多难度模式（硬核/棱彩/王朝）
❌ 全明星周末小游戏
❌ 征服联盟成就
❌ 深度球队经营（交易市场、工资帽博弈）

以上都能后期加，首发版本一律砍掉。

## 十、技术选型建议

- **纯静态单页**（HTML + 原生 JS 或 Vite + React），localStorage 存档
- 数据预处理成一份精简 JS/JSON，避免运行时解析 25 MB
- 分享卡用 `canvas` 绘制导出 PNG
- 参考实现（可看结构，勿直接抄）：`https://zyz9408.github.io/perfect-player/`

## 十一、开发顺序

1. **数据 ETL + 年代归一化**（1–2 天）→ 产出 `players.json`（每年代一套归一化 13 属性）
2. **建球员流程**（1–2 天）→ 选年代/位置/抽球队/13 轮夺属性/揭幕 OVR
3. **赛季模拟引擎**（2–3 天）→ 82 场 + 场均数据 + 评奖 + 季后赛
4. **生涯循环**（1–2 天）→ 休赛期加点 + 事件 + 衰减 + 退役评级
5. **UI + 分享卡**（1–2 天）

**合计约 1–2 周可出可玩版本。**
